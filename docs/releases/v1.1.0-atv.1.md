# Findroid TV v1.1.0-atv.1

Findroid TV is an unofficial, experimental Android TV fork maintained by `darvilp`. The upstream Findroid project does not support or endorse this release. Report problems through the [Android TV feedback form](https://github.com/darvilp/findroid/issues/new?template=android-tv-feedback.yml), not to upstream Findroid.

This release is based on upstream Findroid 1.1.0 and includes the MPV playlist fix in [commit 549a0382](https://github.com/darvilp/findroid/commit/549a038292e62bf8f9b46d39270779ed3fc57e20). The application ID is `dev.jdtech.jellyfin.atv`, so Findroid TV installs separately from official Findroid and debug builds. It uses separate app data, so sign in to your Jellyfin server after installation.

## Choose an APK

- Use `arm64-v8a` for TVs running 64-bit ARM Android.
- Use `armeabi-v7a` for TVs running 32-bit ARM Android, including TVs with a 64-bit processor but 32-bit Android.
- If you do not know the device ABI, use the larger universal APK.
- The `x86` and `x86_64` APKs target emulators.

## Android TV changes

- Remote-first navigation for browsing, search, playback controls, held seeking, chapters, episodes, and item details
- ExoPlayer and MPV player selection, including pre-play audio and subtitle track selection
- MPV hardware-decoding control plus audio and subtitle synchronization controls
- Played-state actions for episodes and home items
- Playback completion, playlist, media-segment, and focus fixes for TV use
- MPV queued-episode replacement fix for crashes when changing audio or subtitle tracks

## Known limitations

- This prerelease can contain navigation, playback, focus, and device-specific bugs.
- Playback depends on the selected player, the device decoders, the media formats, and the Jellyfin server's playback decision.
- Findroid TV does not guarantee Direct Play or universal codec support.
- Physical-TV compatibility has limited device coverage; additional device reports are requested.
- An MPV startup race with a preloaded queue and a nonzero starting index is tracked in [issue #13](https://github.com/darvilp/findroid/issues/13). It is reproduced in adapter tests, not ordinary app playback. Findroid initially loads only the requested item at index zero.

## Sideload the APK

1. Enable Android debugging on the target device.
2. Connect ADB to the device.
3. Install the APK:

   ```sh
   adb install <apk-file>
   ```
