# Findroid TV v1.1.0-atv.2

Findroid TV is an unofficial, experimental Android TV fork of Findroid maintained by `darvilp`. Report issues using the [Android TV feedback form](https://github.com/darvilp/findroid/issues/new?template=android-tv-feedback.yml).

The changes in this prerelease are limited to CI and Kotlin formatting.

## Changes

- Upgrade ktfmt so GitHub Actions checks Android Kotlin production and test sources.
- Run the formatting workflow when the Gradle version catalog changes.
- Apply the existing Kotlin formatting style across the Android modules.

[Compare with v1.1.0-atv.1](https://github.com/darvilp/findroid/compare/v1.1.0-atv.1...v1.1.0-atv.2)

## Choose an APK

- Use `arm64-v8a` for TVs running 64-bit ARM Android.
- Use `armeabi-v7a` for TVs running 32-bit ARM Android, including TVs with a 64-bit processor but 32-bit Android.
- Use the universal APK if you do not know your device's ABI.
- The `x86` and `x86_64` APKs target emulators.

The application ID is `dev.jdtech.jellyfin.atv`. To update an existing Findroid TV installation, connect ADB and run `adb install -r <apk-file>`.
